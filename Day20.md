# Day 20 – AI Face Puzzle Game using Claude

## 🎯 Objective

Build a complete **Face Puzzle Game** using Claude AI that captures the user's face through the webcam and converts it into an interactive drag-and-drop puzzle.

# 💡 Key Learnings

* Learned how to access webcams using the MediaDevices API.
* Understood the working of `getUserMedia()` and browser permissions.
* Learned image capture using the HTML Canvas API.
* Explored image slicing techniques for puzzle generation.
* Implemented drag-and-drop interactions using JavaScript.
* Added touch gesture support for mobile devices.
* Built a real-time timer using JavaScript intervals.
* Tracked player moves dynamically.
* Implemented automatic puzzle completion detection.
* Stored leaderboard data using LocalStorage.
* Improved responsive UI design for multiple screen sizes.
* Learned how AI can generate complete production-ready frontend applications from a detailed prompt.
* Experienced how prompt quality directly impacts the quality of generated applications.
