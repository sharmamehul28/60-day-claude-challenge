# 🏥 Day 27 – Prior Authorization Story Simulator

## 📌 Project Overview

On Day 27 of the ABTalks 60 Days AI Challenge, I built an interactive **Prior Authorization Story Simulator** using Claude AI.

This application explains the U.S. healthcare Prior Authorization (PA) process through an engaging, story-driven chat experience. Instead of presenting the workflow as a technical process, the simulator follows Rahul's healthcare journey while Priya explains every step in simple, beginner-friendly language.

The project combines storytelling, healthcare education, and interactive web development into a single HTML application.

---

# 🎯 Objective

- Simplify the Prior Authorization process
- Build an interactive story-based learning experience
- Create a branching conversation system
- Educate users with real healthcare workflows
- Improve user engagement through storytelling

---

# 📖 Story Journey

The simulator follows Rahul through eight interactive chapters:

1. Doctor Visit
2. Insurance Roadblock
3. What is Prior Authorization?
4. Insurance Review
5. Denial
6. Appeal
7. Approval
8. Final Takeaways

Each chapter includes educational explanations and user choices that influence the conversation flow.

---

# 👥 Characters

### 👦 Rahul

The patient experiencing the Prior Authorization journey.

### 👧 Priya

A healthcare operations specialist who explains every stage in simple language.

### 👨‍⚕️ Doctor & Narrator

Displayed as centered educational text to guide the story.
