# 📄 Day 39 – PDF Splitter & Merger

## 📌 Overview

Today, I built **Sheaf – PDF Splitter & Merger**, a premium offline PDF utility that enables users to split and merge PDF documents directly in the browser without uploading files to any server.

The application is designed around a **paper workshop desk** concept, providing an intuitive and professional experience for document management while ensuring complete client-side processing.

---

## 🎯 Project Objective

Develop a secure, modern, and fully offline PDF management tool that allows users to split, merge, preview, and organize PDF documents with a polished user experience.

---

## ✨ Features

### 📄 PDF Splitter
- Upload PDF Files
- Automatic Page Detection
- PDF Page Thumbnails
- Split by Custom Page Ranges
- Split After Specific Pages
- Split Every N Pages
- Click-to-Extract Pages
- Live Input Validation
- Output Preview Before Processing

### 📚 PDF Merger
- Drag & Drop Multi-file Upload
- Drag-to-Reorder PDF Files
- Live File & Page Statistics
- Estimated Output Size
- One-Click PDF Merge
- Download Merged PDF

### 🎨 User Experience
- Dark Theme
- Moss & Clay Accent Palette
- Responsive Layout
- Toast Notifications
- Progress Overlay
- Smooth Animations
- Keyboard Shortcuts
- Accessibility Support
- Fully Offline After Initial Load

---

## 🛠 Technologies Used

- HTML5

## 📚 Key Learnings

- Client-side PDF processing improves user privacy and security.
- Drag-and-drop workflows make document management more intuitive.
- Live validation reduces processing errors.
- Previewing output before processing improves usability.
- Browser-based JavaScript libraries can create powerful document tools without a backend.
