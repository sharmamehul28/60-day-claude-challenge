## 🚀 Final Project

**JobTrack AI** is a focused job-search command center built for students and freshers.

It helps users manage job applications, track resume versions, understand application progress through analytics, and identify what needs attention next.

### 🌐 Live Application

https://jobtrack-ai-nine.vercel.app/

### 💻 GitHub Repository

https://github.com/sharmamehul28/Jobtrack-ai

---

## 🎯 What I Built

JobTrack AI includes:

* 🔐 Secure user authentication
* 📋 Job application CRUD
* 📄 Resume version management
* 🔗 Resume-to-application linking
* 📊 Analytics dashboard
* 🧠 Smart Career Assistant
* 🔔 Follow-up and attention insights
* 🌗 Light/Dark mode
* 📱 Responsive design
* 🔒 Supabase Row Level Security
* 🚀 Production deployment on Vercel

The Smart Career Assistant uses deterministic, rule-based logic rather than external LLM API calls. This keeps the feature fast, predictable, and cost-free.

## 📅 10-Day Capstone Journey

### Day 1 — Requirements & Product Planning

Defined the product problem, scope, requirements, and implementation direction for JobTrack AI.

### Day 2 — Architecture & Environment

Established the React/Vite frontend, Supabase backend infrastructure, database structure, authentication foundation, and development environment.

### Day 3 — Landing Page & Authentication

Built the landing experience and authentication flow with protected application areas.

### Day 4 — Application Tracker

Implemented the core application management workflow with create, read, update, and delete functionality.

### Day 5 — Resume Version Manager

Added resume version tracking and connected resume versions with job applications.

### Day 6 — Analytics Dashboard

Built the dashboard to visualize application activity, status distribution, interviews, offers, and conversion metrics.

### Day 7 — Smart Career Assistant

Implemented rule-based career guidance using the user's own application data to identify follow-ups, stuck applications, and suggested next actions.

### Day 8 — UI/UX Polish

Focused on responsive behavior, visual consistency, usability, and light/dark mode.

### Day 9 — Testing & QA

Performed end-to-end verification, handled edge cases, improved reliability, and prepared the application for production.

### Day 10 — Final Deployment, Documentation & Graduation

Completed final production verification, documentation, portfolio preparation, and Version 1.0.0 release preparation.

## 🎓 Graduation Reflection

The AB Talks 60-Day Claude AI Challenge started as an opportunity to learn AI and experiment with what could be built using it.

Over the course of the challenge, the focus expanded from AI fundamentals and prompting into research, workflows, automation, product thinking, AI-assisted development, debugging, and increasingly complex application-building concepts.

The final 10-day capstone brought those skills together.

JobTrack AI became the practical demonstration of that progression — taking an idea through requirements, architecture, implementation, testing, deployment, documentation, and final release.

The most valuable lesson was learning to use AI as a development partner rather than simply a tool for generating answers.

The project is now shipped as Version 1.0.0.

**60 days completed.
10-day capstone completed.
JobTrack AI shipped.**
