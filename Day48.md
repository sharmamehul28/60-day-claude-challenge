# Day 48 — Compare & Decide Builder

## 🎯 Objective

Build a research-backed comparison tool that helps users make better decisions by comparing multiple options and allowing them to prioritize what matters most.

## 🚀 What I Built

I built a **Compare & Decide Builder** that compares four laptops:

* MacBook Air M4
* Dell XPS 13 (2026)
* Surface Laptop 7
* ThinkPad E14 Gen 6

The laptops are evaluated across:

* Price
* Battery Life
* Performance
* Storage & RAM Value
* Build Quality

## ✨ Key Features

* Adjustable criteria weights
* Live ranking updates
* Research-backed comparison data
* Citable sources for data points
* Estimate indicators for uncertain data
* Sources panel
* Collapsible "How this was researched" panel
* Source conflict explanations
* Responsive design
* Loading, empty and edge-state handling

## 🛠️ Tech Stack

* HTML
* CSS
* Vanilla JavaScript
* Single self-contained HTML file
* No external libraries

## 🔬 Research & Transparency

The application is designed around real, citable data rather than invented scores.

Each comparison data point is connected to its source, while estimates are clearly identified. The research panel also explains differences or conflicts between sources.

## 🧪 Testing

Tested the application by:

* Changing criteria weights
* Observing live ranking changes
* Reviewing the sources panel
* Reviewing the research methodology
* Testing responsive layouts
* Checking edge cases

## 📚 Key Learnings

* Weighted scoring can personalize decision-making.
* Data-driven tools need transparent sources.
* Users should be able to understand why rankings change.
* Conflicting sources should be acknowledged and explained.
* Good UX can make complex research easier to understand.

## 💡 Key Takeaway

**The best option isn't always the same for everyone. The best decision depends on what matters most to the person making it.**
