# 🚀 Day 10 – AI-Powered Personal Portfolio Website

## 📌 Objective

The objective of Day 10 was to use Claude AI to generate a complete, responsive personal portfolio website. This exercise focused on prompt engineering, AI-assisted web development, and creating a professional online portfolio.

---

# 🛠️ Project Overview

Using the provided portfolio prompt, I customized the placeholders with my personal information and generated a fully functional portfolio website. The application showcases my skills, projects, education, and contact information in a modern, responsive design.

---

# ✨ Portfolio Features

* Responsive and modern user interface
* Hero section with introduction
* About Me section
* Technical Skills showcase
* Featured Projects section
* Education details
* Contact section with social links
* Smooth scrolling and interactive elements
* Mobile-friendly design
* Single HTML file with integrated HTML, CSS, and JavaScript

# 💡 Key Learnings

* Learned how AI can generate a complete portfolio website from a single well-structured prompt.
* Understood the importance of replacing placeholders with accurate personal information for personalized results.
* Improved my understanding of responsive web design and modern portfolio layouts.
* Practiced testing AI-generated HTML applications before publishing.
* Learned how to document AI-generated projects professionally on GitHub.
* Realized that refining prompts leads to cleaner code and better UI/UX.
* Strengthened my knowledge of AI-assisted frontend development.

---

# 🎯 Conclusion

This project demonstrated how AI can accelerate the process of building professional portfolio websites. By combining prompt engineering with frontend development, I was able to generate a modern, responsive portfolio that showcases my skills and projects while improving my understanding of AI-assisted web development.
