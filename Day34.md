# 📅 Day 34 – Marketing Detective

## 📌 Project Overview

On Day 34 of the **ABTalks 60 Days AI Challenge**, I built an interactive **Marketing Detective** web application using HTML, CSS, and JavaScript.

This application transforms marketing analysis into a detective-style investigation where users solve fictional campaign cases by examining evidence, identifying marketing mistakes, and learning from expert explanations.

The project combines interactive UI, gamification, and marketing concepts to create an engaging learning experience.

---

# 🚀 Features

- 🎨 Multiple Theme Selection (Including Claude Orange)
- 🕵️ Detective Style User Experience
- 📂 Random Marketing Investigation Cases
- 📌 Interactive Investigation Board
- 🧩 Draggable Evidence Cards
- 📊 Campaign Performance Analysis
- 📈 Marketing Learning Report
- 🔄 Replay with Randomized Cases
- 📱 Fully Responsive Design
- 🌐 Offline Single HTML File

---

# 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

# 🔍 Investigation Process

### Case Assignment
Received a fictional marketing campaign with campaign metrics, audience details, customer feedback, and social media performance.

### Investigation Board
Analyzed available evidence to identify the root cause of poor campaign performance.

### Evidence Analysis
Dragged and organized clues to understand relationships between campaign metrics and customer behavior.

### Case Solution
Identified the primary marketing mistake and compared it with the expert explanation.

### Learning Report
Reviewed recommendations, campaign improvements, and key marketing lessons.
