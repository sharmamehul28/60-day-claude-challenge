# 📄 Day 11 – ATS Resume Optimization with Claude AI

## 📌 Objective

The objective of Day 11 was to optimize my resume using Claude AI by comparing it against a target Data Analyst Job Description. The process included generating an ATS analysis, identifying skill gaps, and creating an ATS-friendly resume tailored to improve job application success.

---

# 🛠️ Project Overview

Using Claude AI and an ATS Resume Optimizer prompt, I uploaded my resume and evaluated it against a Data Analyst Job Description. Claude generated an ATS Match Score, performed a detailed gap analysis, and suggested improvements. Based on these insights, I created an optimized resume with stronger keywords, improved formatting, and role-specific content.

---

# 📊 ATS Analysis

1. ATS Match Score: 62/100
Solid foundation in data analysis fundamentals (Python, Pandas, Power BI, Excel) but missing explicit SQL project experience and dashboard/statistics keywords in context.
2. Gap Analysis
Missing Keywords: "Business insights," "KPIs," "stakeholders," "reporting," "data validation," "Tableau," "ETL," "Machine Learning"
Missing Skills (per resume, not fabricated): Statistics isn't explicitly named (though implied via data analysis); ETL Concepts and Machine Learning Fundamentals are listed as preferred but absent — cannot be added without fabrication.
Improvement Opportunities:

SQL is listed as a skill but never demonstrated in a project — reframe existing project bullets to surface SQL/data validation work already implied.
Lead with data analytics identity over "full-stack" framing, since the JD is analyst-focused.
Quantify impact language already present, using action verbs aligned to JD terms (e.g., "insights," "trends").

# 📄 Optimized Resume

An ATS-friendly version of my resume was generated based on the recommendations provided by Claude AI.

* Added role-specific keywords from the Job Description

* Optimized technical skills for ATS compatibility
